# Zeno QuickBooks Continuity

Use the `qb_*` tools from Zeno, the local MCP server on Windows.

1. Start with `qb_list_plans` for pending batches. Surface reviewed but
   unapplied work before new overlapping work.
2. Check `qb_list_playbooks` before improvising a recurring procedure. Run only
   confirmed playbooks; returned steps are instructions, not completed work.
3. Treat confirmed knowledge surfaced in results as a colleague's note, not as
   company-file data. Say when it materially affects a decision.
4. Use rules only for deterministic mappings. Use knowledge for facts,
   quirks, and judgment that need context.
5. Write durable knowledge and playbooks as drafts. A human must read and
   confirm them; do not confirm the model's own draft.
6. Use `qb_log_work` as work proceeds. Record the source, what changed, why,
   what remains open, and relevant plan or run IDs.

When handing work off, distinguish clearly between prepared, reviewed,
applied, partially failed, reversed, and still-open items. Never infer that a
plan was approved merely because another session prepared it.
